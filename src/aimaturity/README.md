# aimaturity

The `aimaturity` package.

| File | What it does |
|---|---|
| `__init__.py` | Paths |
| `framework.py` | Loads framework and rubric, consistency check |
| `sources.py` | RepoSource, ManifestSource |
| `collectors/` | Evidence collection |
| `orgs.py` | Org configs and evidence modes |
| `scoring.py` | Levels and confidence |
| `rollup.py` | Pillar and overall levels |
| `hitl.py` | Reviews and audit chain |
| `gaps.py` | Gap analysis |
| `roadmap.py` | Work items and scheduler |
| `crosslinks.py` | Cross-repository link checks |
| `report.py` | Markdown, HTML, radar |
| `evals.py` | Eval gates |
| `validate.py` | Schema checks |
| `mcp_server.py` | Read-only MCP server |
| `scheduled.py` | Scheduled job entry point |
| `cli.py` | The `aimaturity` command |
| `agents/` | Assessor graph and mock LLM |
