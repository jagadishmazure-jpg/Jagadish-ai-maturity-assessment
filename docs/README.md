# docs

Documentation. Outputs and code excerpts are regenerated by `scripts/render_docs.py` and checked in CI. Every doc in `pillars/`, `components/`, `samples/` and `infra/` has the same 17 sections, ending with Adopt this.

| File | What it does |
|---|---|
| `pillars/` | The six pillars (framework-derived tables under CC BY-SA 3.0 IGO) |
| `components/` | Agent, collectors, scoring, HITL, roadmap, report, evals, MCP, A2A |
| `samples/` | The three sample assessments |
| `infra/` | Terraform, Bicep, scheduled job, workflows |
| `adr/` | Architecture decision records |
| `architecture.md` | Components, data flow, licensing boundary, Azure mapping |
| `implementation-guide.md` | Clone to demo to your own organisation to Azure |
| `interview-guide.md` | Two, ten and thirty-minute walk-throughs and Q&A |
| `best-practices.md` | The rules this repository follows and what enforces them |
| `deployment.md` | Gated deployment and one-time setup |
| `adopt-this.md` | How another team reuses, configures and extends it |
